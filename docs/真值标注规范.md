# 真值标注规范

> 这份规范服务于两件事：**① 可行性验证实验（V0）**，**② 以后所有回归测试的基准**。
> 没有真值，任何算法改动都只能靠"感觉对了"，参数永远调不准——这是上一份可行性分析里
> 最该先投的一笔非代码工作。
>
> 相关：[Loop 和声提取可行性分析](./Loop和声提取可行性分析.md)、[测试语料清单](../testdata/midi/语料清单.md)

---

## 一、为什么要标、标来干什么

| 用途 | 说明 |
| --- | --- |
| 可行性验证 | 只测"调性判定准不准"这一件事，半天就能出结论 |
| 回归测试 | 以后每改一次算法，跑一遍就知道有没有退化 |
| 调参依据 | 打分权重、窗口大小、分段阈值，全靠真值来选 |
| 争论的裁断 | 输出"怪结果"时，能明确是算法错了还是素材本身就怪 |

> 校准过的事实：**文件名不可靠**。`Cymatics Bonus MIDI - Am_110bpm.mid` 实测分析是 C 大调（0.91），
> 文件名写的是 Am。所以真值必须人工标，不能靠文件名自动生成。

## 二、标什么、不标什么

### 要标

| 项 | 精度要求 |
| --- | --- |
| 调性 | 主判定必有；模糊时加次判定 |
| 和弦段 | 每段的起始位置 + 持续拍数 + 和弦名 + 低音 |
| 和声节奏 | 默认多久换一次和弦（每小节 / 每两拍 / 每拍） |
| 低音 | 每段的最低音是谁 |

### 不标

| 项 | 原因 |
| --- | --- |
| 音的排列（密集/开放/drop 几） | 分析层不需要，属于生成层面 |
| 力度、音色、鼓组 | 与和声无关 |
| 装饰音的具体类型（倚音/经过音） | 只标"这里有外音"，不细分 |
| 精确的延伸音（9/11/13） | 只标折叠后的和弦名，精确写法可选填 |

## 三、一条 loop 要标哪些字段

| 字段 | 代码名 | 必填 | 取值说明 |
| --- | --- | --- | --- |
| 文件 | `file` | ✅ | 相对 `testdata/midi/` 的路径 |
| 小节数 | `bars` | ✅ | 含小数（如 4.5） |
| 拍号 | `timeSig` | ✅ | 如 `"4/4"` |
| 速度 | `bpm` | ✅ | 文件里有 tempo 事件就填数字；**没有就填 `null`**（不要猜） |
| 调性（主） | `key` | ✅ | 如 `"C 大调"`、`"A 小调"`；判不出填 `"? "` |
| 调性（次） | `keyAlt` | 可选 | 模糊时的另一种可能，如 `"A 小调"` |
| 是否模糊 | `ambiguous` | ✅ | 关系大小调分不清时填 `true` |
| 单声部 | `singleLine` | ✅ | 只有旋律/贝斯、不该出和弦时填 `true` |
| 和声节奏 | `harmonicRhythm` | ✅ | 人话描述，如 `"每 2 拍"`、`"每小节"`、`"不规则"` |
| 段列表 | `segments` | ✅ | 见下 |
| 备注 | `note` | 可选 | 特殊之处，如"第 3 段是琶音"、"低音是持续音" |

### 每一段（segment）

| 字段 | 代码名 | 必填 | 说明 |
| --- | --- | --- | --- |
| 位置 | `at` | ✅ | `"小节.拍"`，如 `"2.3"` 表示第 2 小节第 3 拍；**允许半拍**（`"2.1.5"` 或直接 `2.5` 拍位） |
| 持续拍数 | `beats` | ✅ | 该和弦持续几拍 |
| 和弦名 | `chord` | ✅ | **折叠后的名字**：`C`、`Am7`、`F`、`C/E` |
| 低音 | `bass` | ✅ | 该段最低音，如 `"C"` |
| 是否斜杠 | `slash` | ✅ | 低音不属于该和弦时 `true` |
| 精确写法 | `exact` | 可选 | 调试用，如 `"Cmaj9/D"`；不填也可以 |
| 把握程度 | `sure` | ✅ | `高` / `中` / `低`——**这一项比什么都重要** |

> `sure` 用来区分"真值"和"猜测"。后续统计指标时，低把握的段可以单独列出，不混进主指标。

## 四、粒度规则（最容易标错的地方）

### 1. 位置精确到半拍

采样包的和弦常在半拍处换（合成器侧链、切分节奏）。精确到 1 拍会把"半拍处换和弦"抹平。
所以位置允许写半拍，例如：`"1.1"`（第 1 小节第 1 拍）、`"1.2.5"`（第 1 小节第 2 拍半）。

### 2. 和弦名用"折叠后"的名字

| 听到的 | 标成 | 不要标成 |
| --- | --- | --- |
| C + E + G + A（低音 C） | `C` | `C6` |
| C + E + G + B + D（低音 C） | `Cmaj7` | `Cmaj9` |
| C + E + G + Bb + D + F# | `C7` | `C13#11` |
| 低音持续的 C 大调和弦 | `C` | `Cmaj9/D` |

> 判断标准：**你在 DAW 里会怎么写这个和弦？** 就怎么标。
> 延伸音太多时，只保留到七音；九音以上记在备注里。

### 3. 斜杠只在"低音不属于该和弦"时用

- 低音是根音 → `C`
- 低音是三音或五音（转位）→ `C/E`、`C/G`，`slash` 填 `false`（它仍然属于该和弦）
- 低音完全不属于该和弦 → `C/D`，`slash` 填 `true`

### 4. 持续低音单独标注

如果低音连续好几段都是同一个音（比如一直踩着 C），那不是每段都变成了 `C/C`，
而是**持续低音**。这种情况下：和弦名按上方和声写，低音写在 `bass` 字段，备注里注明"持续低音"。

### 5. 外音不算和弦音

旋律音、经过音、装饰音，即使是长音，只要不构成和弦，就不参与和弦命名。
如果某个外音很显眼（比如一直挂着的九音），记在备注里。

## 五、歧义怎么处理

### 关系大小调分不清

C 大调与 A 小调共用同一套音，短 loop 里经常分不清。规则：

1. 你**觉得更像哪个**就填在 `key`；
2. 另一个填在 `keyAlt`；
3. `ambiguous` 填 `true`；
4. 备注写依据，如"低音落在 A，但和弦进行更像 C 大调"。

> 这个标记非常重要：它决定了评估时这条算不算"错"。标了模糊的，两个答案都算对。

### 确实听不出来

`chord` 填 `"?"`，`sure` 填 `低`。**禁止瞎猜**——错的真值比没有真值有害得多。

### 同一个和弦有多种叫法

`C E G A` 可以是 `C6` 也可以是 `Am7`。规则：**按低音判**。
低音 C → `C`；低音 A → `Am7`。备注里记下另一种可能。

## 六、文件格式

用 **JSONL**（一行一条，人能读、机器能算）。放在 `testdata/midi/真值.jsonl`。

```jsonl
{"file":"01-柱式和弦/Cymatics - Lofi MIDI 1 - C Maj.mid","bars":4,"timeSig":"4/4","bpm":null,"key":"C 大调","keyAlt":null,"ambiguous":false,"singleLine":false,"harmonicRhythm":"每 2 拍","segments":[{"at":"1.1","beats":2,"chord":"C","bass":"C","slash":false,"exact":"Cmaj7","sure":"高"},{"at":"1.3","beats":2,"chord":"F","bass":"F","slash":false,"exact":"Fmaj7","sure":"高"}],"note":"实测分析 C 大调 0.82"}
```

说明：
- 一行必须能独立成立（不要跨行）
- 空值时填 `null`，不要省略字段（方便脚本处理）
- `exact` 可以不填；`note` 可以不填

## 七、标多少、挑哪些

**目标 12–20 条**，覆盖下面六类（每类至少 2 条）：

| 类别 | 从哪挑 | 要验证什么 |
| --- | --- | --- |
| 柱式和弦 | `01-柱式和弦/` 6 个文件 | 基础准确率 |
| 琶音 | `02-琶音/` 3 个文件 | 分段聚合 |
| 单声部 | `03-单声部/` 4 个文件 | 必须拒答 |
| 完整编曲 | `04-完整编曲/`（挑固定的 2–3 段） | 分轨与多声部 |
| 极稀疏 | `04-完整编曲/015 Midi…` 的和声层 | 低密度下的判定 |
| 点状切分 | `04-完整编曲/JustJazz和弦钢琴-第1至8小节.mid` | 极短时值 |

**优先标短文件**（4–8 小节）。长的先不标，等基础准确率达标再说。

## 八、标注流程（没有耳朵也能标）

你手上没有音频，只能读音符。推荐三步：

1. **看音符表**：用现有工具的"音符列表"或"钢琴卷帘"，把那一段的音符铺开看。
   本仓库的 `MIDI写作手法清单` 里记录了哪些文件有坑（比如完全重复音符）。
2. **找低音**：找出每拍/每半拍的最低音。低音变化的地方，九成就是和弦变化点。
3. **判和弦**：从低音出发，看上面叠了什么三度音，再定大小调和七音。
   不确定的时候，先写在备注，`sure` 标 `中`。

> 一个小技巧：先标柱式和弦那 6 个，手感练出来了再标琶音和混装——它们的判定难度高一档。

## 九、提交前自检

勾一遍，缺一条就说明数据有问题：

- [ ] 每一段的 `at` 起点，都等于上一段的 `at + beats`（首尾相接，不留空、不重叠）
- [ ] 所有段加起来等于 `bars` 对应的小节数
- [ ] `chord` 里的名字能在常用和弦表里查到（或写成 `?`）
- [ ] `slash` 为 `true` 时，`bass` 一定不属于 `chord` 的构成音
- [ ] `ambiguous` 为 `true` 时，`keyAlt` 必须有值
- [ ] `singleLine` 为 `true` 时，`segments` 必须为空
- [ ] 文件里没有 tempo 事件时，`bpm` 必须是 `null` 而不是 120

## 十、附录：和弦写法对照

标注时统一用"常用记号"（左边那列）：

| 常用记号 | 含义 | 别的写法 |
| --- | --- | --- |
| `C` | 大三和弦 | `Cmaj` |
| `Cm` | 小三和弦 | `Cmin`、`C-` |
| `C7` | 属七 | `Cdom7` |
| `Cmaj7` | 大七 | `CM7`、`CΔ7` |
| `Cm7` | 小七 | `Cmin7`、`C-7` |
| `Cm7b5` | 半减七 | `Cø7` |
| `Cdim7` | 减七 | `C°7` |
| `Caug` | 增三 | `C+` |
| `Csus4` | 挂四 | `Csus` |
| `C6` | 加六 | `Cadd6` |
| `C/E` | 转位（低音是 E） | — |
| `C/D` | 斜杠和弦（低音 D 不属于 C） | — |
| `?` | 判断不出 | — |
