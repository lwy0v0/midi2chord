# 钢琴卷帘窗组件 `PianoRoll`

> 一个可搬走的 Vue 组件：给音符数据，实时画出来。不依赖本项目的任何业务类型。
> 位置：`src/components/PianoRoll.vue`（单文件，模板 + 逻辑 + scoped 样式都在里面）。
> 以后做别的音乐应用（MIDI 编辑器、采样器、打谱工具）可以直接整份复制过去。

---

## 为什么这么设计

| 设计约束 | 做法 | 原因 |
| --- | --- | --- |
| **可移植** | 零业务依赖，只认 `pitch / start / duration` 三个必填字段 | 换项目不用改组件 |
| **能扛住真实数据** | Canvas 渲染，不是 DOM/SVG | 一次要画几千个音符，DOM 到 6000 个就卡 |
| **实时** | props 变化触发重绘，用 `requestAnimationFrame` 合并连续变更 | 拖时间轴、换文件都不会掉帧 |
| **交互** | 悬停出提示条、点击回传原始数据 | 组件不理解数据含义，由调用方决定怎么用 |
| **样式自包含** | scoped CSS 全在组件内 | 搬走时不会丢样式，也不会污染宿主 |

---

## 数据约定

组件只认这两种结构（在组件文件的普通 `<script>` 块里导出，可直接 `import type`）：

```ts
import PianoRoll, { type RollNote, type RollSegment } from "./components/PianoRoll.vue";

/** 一个音符。时间单位是「拍」，与拍号无关。 */
interface RollNote {
  pitch: number;        // MIDI 音高 0..127（60 = C4）
  start: number;        // 起始位置（拍）
  duration: number;     // 时长（拍）
  group?: string;       // 着色分组键，如 "root" / "melody"
  velocity?: number;    // 0..127，只用于透明度
  data?: unknown;       // 附加数据，点击时原样回传
}

/** 背景区块（和弦段、段落标记之类）。 */
interface RollSegment {
  start: number;
  duration: number;
  label?: string;       // 画在块左上角
  group?: string;
  data?: unknown;
}
```

**只有 `pitch` / `start` / `duration` 是必填的**，其余都可以不给。

## 属性

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `notes` | `RollNote[]` | 必填 | 音符列表 |
| `segments` | `RollSegment[]` | `[]` | 背景区块 |
| `beatsPerBar` | `number` | `4` | 每小节几拍（决定小节线位置） |
| `totalBeats` | `number` | 自动 | 总长度；不给就按内容算 |
| `pitchMin` / `pitchMax` | `number` | 自动 | 锁定音域；不给就按内容算（上下各留 1 个半音） |
| `beatWidth` | `number` | `46` | 每拍多少像素 |
| `rowHeight` | `number` | `9` | 每个半音多少像素 |
| `colors` | `Record<string, string>` | `{}` | 分组 → 颜色；没给的分组按调色板自动分配 |
| `selectedSegment` | `number \| null` | `null` | 高亮第几个区块 |
| `noteLabel` | `(note, index) => string` | 内置 | 悬停提示条的文字 |
| `maxHeight` | `number` | `360` | 超出滚动 |
| `showPitchLabels` | `boolean` | `true` | 左侧音名条 |

## 事件

| 事件 | 参数 | 触发 |
| --- | --- | --- |
| `note-click` | `(note, index)` | 点到音符 |
| `segment-click` | `(segment, index)` | 点到背景区块（且没点到音符） |

## 暴露方法

| 方法 | 用途 |
| --- | --- |
| `redraw()` | 手动重绘。**如果你原地修改了数组**（不是替换引用），调一次它 |

> 通常只要替换数组引用（`notes.value = newArray`）就会自动重绘。

## 最小示例

```vue
<script setup lang="ts">
import PianoRoll, { type RollNote, type RollSegment } from "@/components/PianoRoll.vue";

const notes: RollNote[] = [
  { pitch: 60, start: 0, duration: 1, group: "root" },
  { pitch: 64, start: 0, duration: 1, group: "third" },
  { pitch: 67, start: 0, duration: 1, group: "fifth" },
  { pitch: 72, start: 1, duration: 0.5, group: "melody", velocity: 80 },
];

const segments: RollSegment[] = [{ start: 0, duration: 2, label: "C" }];

const colors = { root: "#3b82f6", third: "#60a5fa", fifth: "#22d3ee", melody: "#94a3b8" };
</script>

<template>
  <PianoRoll :notes="notes" :segments="segments" :colors="colors" />
</template>
```

## 本项目怎么用的

在本项目里，`MidiAnalysisPanel.vue` 把分析结果映射成组件要的形状（**这一步是唯一的耦合点**）：

```ts
// 音符：角色 → 颜色分组
const rollNotes = computed<RollNote[]>(() =>
  (result.value?.notes ?? []).map((n) => ({
    pitch: n.pitch,
    start: n.startBeat,
    duration: n.durBeats,
    group: n.role,          // root/third/fifth/seventh/extension/melody/outside
    velocity: n.velocity,
    data: n,
  })),
);

// 和弦段：映射成背景块，标签就是和弦名
const rollSegments = computed<RollSegment[]>(() =>
  (result.value?.segments ?? []).map((s) => ({
    start: s.startBeat,
    duration: s.lenBeats,
    label: s.chord.symbol,
    group: "chord",
    data: s,
  })),
);
```

配色表在 `src/api/midi.ts` 里（`NOTE_ROLE_COLORS`），换个项目只要改这个表。

## 移植说明

组件本身**没有 import 任何项目内的东西**，只依赖 Vue 3。搬到新项目：

1. 复制 `src/components/PianoRoll.vue` 过去；
2. 确认目标项目支持 `<script setup lang="ts">` 与 scoped CSS（Vue 3 SFC 默认就支持）；
3. 传 `notes` 就能跑。

需要一起带走的约定只有一条：**时间单位是拍，不是秒**。
如果数据是秒，调用方自己除以一拍时长再传进来——组件不关心速度。

## 性能

- 画布一次性绘制，6000 个音符的实测场景（`testdata/midi/04-完整编曲/015 Midi … Limitless`）能一帧画完；
- 绘制合并在 `requestAnimationFrame` 里，连续改 props 不会重复画；
- 高频重绘时也不要每次重建画布（组件内部会按 `devicePixelRatio` 设置尺寸，不会反复重置）。

## 已知限制

| 限制 | 说明 |
| --- | --- |
| 没有缩放/平移控件 | 目前靠外层滚动；要缩放就改 `beatWidth` / `rowHeight` |
| 没有选中多个音符 | 只支持点单个音符回调，多选逻辑留给调用方 |
| 没有编辑能力 | 纯展示 + 交互，拖动/改音高需要另做 |
| 深色配色写死 | 背景固定深色（`#161b22` 一类）；要用浅色主题得改 scoped 里的颜色 |
| 音名固定用升号 | 需要降号拼写（`Bb` 而不是 `A#`）时要传自定义 `noteLabel` |

> 这些限制都是**有意为之**：组件越小、依赖越少，越好搬。
